# CLAUDE.md — Todo Angular App

## Mock Backend: json-server + db.json

The mock backend is **json-server** running at `http://localhost:3000`, backed by `db.json` at the project root.

### db.json schema

```json
{
  "users": [{ "id", "username", "email", "role", "password", "createdAt" }],
  "todos": [{ "id", "ownerId", "title", "completed", "createdAt" }]
}
```

### Rules for all feature implementation

1. **All CRUD goes through HTTP, not direct file edits.**
   Never mutate `db.json` by hand in application code. All reads/writes must use `fetch()` against `http://localhost:3000/<resource>`.

2. **Follow standard REST conventions for each operation:**

   | Operation | Method   | URL                        |
   |-----------|----------|----------------------------|
   | List      | `GET`    | `/todos`                   |
   | Filter    | `GET`    | `/todos?ownerId=<id>`      |
   | Get one   | `GET`    | `/todos/<id>`              |
   | Create    | `POST`   | `/todos`                   |
   | Update    | `PATCH`  | `/todos/<id>`              |
   | Delete    | `DELETE` | `/todos/<id>`              |

   Same pattern applies to `/users`.

3. **POST body must include all required fields** defined in the schema above.
   - `todos` POST: `{ ownerId, title, completed: false, createdAt: new Date().toISOString() }`
   - `users` POST: `{ id: crypto.randomUUID(), username, email, role, password, createdAt: new Date().toISOString() }`

4. **Use `PATCH` (not `PUT`) for partial updates.** Only send the fields that changed.

5. **New resources get their id auto-generated by json-server** (string nanoid). Do not manually set `id` on `todos`. For `users`, set `id: crypto.randomUUID()` explicitly (matching current convention in `AuthService`).

6. **Seed data lives in `db.json`.** When a feature needs initial data, add records directly to `db.json` under the correct collection. Never add seed logic in Angular code.

7. **Service layer owns all HTTP calls.** Components never call `fetch()` directly. Each feature's API calls live in a dedicated service (e.g., `TodoApiService`, `AuthService`).

8. **Base URLs are constants at the top of each service file**, not hardcoded strings inline:
   ```ts
   const TODO_API_URL = 'http://localhost:3000/todos';
   ```
